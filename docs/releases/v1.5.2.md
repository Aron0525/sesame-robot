# Sesame V3 v1.5.2 发布说明

发布日期：2026-08-17

## 本版本已实现

- **唤醒词与阈值控制**：正式路径使用 ESP-SR MultiNet 的“芝麻阿奇”（`zhi ma a qi`）命令词；控制台可用滑条或输入框以 `0.01` 步长设置 `0.05–0.95` 阈值，设备即时应用并保存至 NVS。
- **安全的阈值恢复**：阈值 NVS 写入由内部 RAM 任务执行，避免 PSRAM 语音任务直接操作 Flash；启动时正确处理布尔返回值，异常保存值会回退到 `0.20`，不会阻止 Wi-Fi/WSS 运行。
- **静默回合处理**：无语音、空 ASR 文本与纯语气词不会调用 OpenClaw 或 TTS，而是结束当前回合并恢复待唤醒；TTS 后追问窗口仍为 3 秒。
- **严格半双工**：没有 AEC 参考通道时，TTS 播放期间不采集麦克风、不运行 VAD/MultiNet；BOOT 键仍可作为显式打断与录音入口。
- **烧录诊断**：烧录脚本识别到唯一 USB 串口却不能自动进入下载模式时，会提示按住 BOOT、短按 RESET/EN 后重新探测。

## 发布边界

- 此 tag 不包含 NVS 配置、Wi-Fi 密码、device token、TLS 私钥、真实录音、训练样本或声纹模型。
- `firmware/speaker_embedding_s3/` 含本地说话人模板，已被 `.gitignore` 排除，不会上传到 GitHub。

## 验证

- Gateway：94 项测试通过。
- ESP32-S3：主机回归测试与 ESP-IDF 构建通过；应用分区保留 55% 空间。
- 真机唤醒率、阈值取值和声学表现仍需以对应环境的烧录后实测为准。
