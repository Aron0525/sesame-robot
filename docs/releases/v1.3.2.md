# Sesame V3 v1.3.2 发布说明

发布日期：2026-08-05

## 版本定位

v1.3.2 是一次基于当前代码和已有实机记录的状态发布。它不把尚未完成的端到端联调写成已交付功能；本说明将“代码已实现”“本机逻辑已验证”和“真实硬件闭环待验收”分别列出。

## 已实现

### 语音与网关

- ESP32-S3 正式固件已包含 I2S 录音/播放、20 ms Opus、WSS、设备 NVS 配置、mDNS 发现、TLS 根证书校验和 BOOT 键回合控制。
- Voice Gateway 已实现 ESP32 Opus 音频接入、ASR → OpenClaw → TTS 编排、响应计划（`response.plan`）、串口事件翻译、本机监控台、设备会话和可中断回合控制。
- OpenClaw 只接收 ASR 文本和受限能力列表；语音、表情与动作按 JSON 契约和网关/设备两层策略校验。

### 对话与联网搜索

- 基础聊天请求、上下文会话和文本回复处理已接入 Gateway/OpenClaw 链路。
- 联网搜索工具已实现：默认关闭；启用后仅 Gateway 使用 DashScope API，OpenClaw 只能提出受限的 `web_search` 工具请求。
- 每个回合最多执行一次搜索；查询长度、时效参数、超时和结果边界均受校验，搜索结果以不可信证据返回给模型生成最终回复。

### 表情与动作

- OLED 表情显示、模型表情白名单、表情持续时间校验和空闲随机眨眼逻辑已实现。
- 本地网页控制支持表情、动作、单路舵机调试和受校验参数；网页动作在独立任务中执行，`STOP ALL` 会取消动作并释放 PWM。
- 模型侧只允许请求 `stop`、`rest`、`stand`、`wave` 四个白名单动作；ESP32 会再次校验动作和表情。

### 已有验证

- 完整 ESP32-S3 固件已完成烧录准备并可启动舵机服务、网页 HTTP 服务、I2S 音频任务、语音任务和 PSRAM 检查。
- 本机 TLS/WSS Voice Gateway 的 HTTPS `/healthz` 已有正常记录。
- Gateway 单元测试、Arduino 网页控制草图编译和 ESP-IDF 主机逻辑测试均纳入仓库验证链路。

## 尚未完成或尚未验收

- 当前实机位置未扫描到 NVS 配置的 2.4 GHz Wi-Fi；因此 WSS `session.hello → session.ready` 尚未在该环境完成验收。
- 完整 P2 硬件闭环仍待实测：BOOT 录音、真实 ASR、OpenClaw 回复、TTS Opus 播放、表情、模型动作和播放中断。
- 动作控制代码和本地网页动作已存在，但模型动作在真实语音闭环中的稳定触发、完成确认和异常恢复仍需继续调试。
- 修正版 OLED 表情显示尚未完成新的实机验证。
- 联网搜索需要本机显式启用 `SESAME_WEB_SEARCH_ENABLED=true` 并配置 DashScope 凭据；它不是默认启用功能。
- 音乐流媒体目前只有方案文档，未纳入本版本可运行功能。

## 继续验收的最短路径

1. 让 ESP32-S3 接入与 Gateway 相同 LAN 的可见 2.4 GHz Wi-Fi。
2. 验证双方日志中的 `session.hello`、`session.ready` 和设备认证记录。
3. 执行一次 BOOT 开始/结束录音，核对 ASR、OpenClaw、`response.plan`、TTS、Opus、表情和动作。
4. 在播放期间按 BOOT，核对 `interrupt`、`tts.flush`、旧 generation 丢弃和动作急停。
