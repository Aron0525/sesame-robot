# Sesame V3 v1.4.2 发布说明

发布日期：2026-08-09

## 本版本已实现

- **「你好芝麻」本地唤醒词**：将专用 TFLite 模型和其嵌入式数据纳入 ESP32-S3 固件；模型完整性、量化参数和阈值由主机测试验证。唤醒后播放本地「我在」提示音。
- **连续语音回合**：固件以 VAD 驱动首次说话、静音断句和最长录音时长；TTS 回复完成后自动打开 3 秒追问窗口，可连续进行下一轮对话。
- **动作控制**：语音响应计划与网页控制共用动作目录，动作、表情、时效和设备安全状态均在本地校验；`stop` 可取消当前动作。
- **网关同步**：Voice Gateway、控制台、协议和设备能力测试同步为上述语音与动作流程。

## 验收边界

- 主机测试覆盖唤醒词模型完整性、唤醒/连续回合状态机、动作目录、动作计划和既有协议路径。
- ESP-IDF 全量编译与真机烧录仍依赖本机 ESP-IDF 5.5.x 工具链、I2S 硬件、网络与云端 ASR/TTS/OpenClaw 配置，需按现场设备继续验收。
