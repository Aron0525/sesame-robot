Sesame Robot V3 · 硬件入门课

接线不是一张表。
它有三种不同的线。

这节课的目标是让你看懂自己的机器人：哪根线传数据，哪根线供电，哪根线必须共地；也知道项目记录尚未证明什么。

约 12 分钟GPIO安全核对
16—A

三种线，不能互相替代

先把这三种概念分开，才不会把“接了 GPIO”误以为“模块已经有电”。

Signal

信号线

例如 GPIO48→/←INMP441 SD，GPIO4→S0。它传递的是数据或控制，不负责给电机供电。

Power

供电线

例如 3V3→麦克风/OLED，5V_SERVO→舵机 V+。它决定模块能不能工作和可承受的电流。

Ground

共同参考地

所有低压模块与 ESP32 的 GND 要有共同参考。舵机电源可以独立，但地不能漂浮。

Bus

共享总线

I2S 的 BCLK、WS 可共享给麦克风和功放；I²C 的 SDA、SCL 是 OLED 总线。数据方向仍各不相同。

16—B

只记住音频这一张小图

它足够解释“为什么当前能录音不代表能播放”。

INMP441：GPIO14→SCK，GPIO47→WS，GPIO48←SD，L/R→GND MAX98357A：GPIO14→BCLK，GPIO47→LRC，GPIO2→DIN，GPIO1→EN 两者共享时钟；各自不共享数据线。 INMP441 未实机录音验收；MAX98357A 与扬声器记录为未安装。
先记方向麦克风的声音数据进入 ESP32，所以箭头是 INMP441 → GPIO48；功放接收 ESP32 要播放的数据，所以箭头是 GPIO2 → MAX98357A DIN。
16—C

舵机不是接到 GPIO 就完成

每个 SG90S 都有 signal、V+、GND 三条线。

组GPIO同组必须检查的供电
S0–S34、5、6、7红线去 5V_SERVO；棕/黑线去共地。
S4–S710、11、12、13同上；不能从 ESP32 3V3 或 USB 数据口取电。

项目记录的 Distro V3 电源树是：电池/USB-C PD → VSYS → 板载 TPS54531 → 5V_SERVO。正式 README 同时要求不要用 USB 给八路舵机供电。理解为：USB Serial/JTAG 仅是主控/数据线；高电流舵机轨必须由合格的 VSYS 来源提供。

16—D

你现在能做的第一个安全核对

无需上电，也无需运行代码。

  1. 断开舵机高电流电源，拍清楚正面/背面照片。
  2. 按照 GPIO 表找 INMP441 的 SCK、WS、SD、L/R；确认 L/R 是 GND。
  3. 找 OLED 的 SDA/SCL，不把模块的上拉接到高于 ESP32 可承受的逻辑电平。
  4. 逐个确认舵机的信号、V+、GND；特别确认所有舵机地与 ESP32 地相连。
  5. 功放和扬声器先不假设已接：当前项目记录没有实机验收。
GPIO14 与 GPIO47 为什么可以分别接两块音频模块？

它们是主控输出的时钟。多个 I2S 从设备监听同一时钟没有问题；但两个设备不能同时驱动同一数据线。

为什么要先断舵机电源？

这样可以在不让机械臂突然动作的情况下确认信号线和地线，避免短路或机械碰撞。
