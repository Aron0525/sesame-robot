# Sesame V3 v1.5.0 发布说明

发布日期：2026-08-12

## 本版本已实现

- **可靠语音采集状态机**：统一手动按键、唤醒词和 TTS 后追问三种采集来源；加入 500 ms PCM 预录音，减少唤醒后开头语音被截断。
- **连续对话与打断**：TTS 完成后开启 3 秒追问窗口；播放期间仅完整唤醒词可触发打断，避免普通环境声误停回复。
- **传输链路加固**：Gateway 连接区分传输建立、协议握手和会话就绪；TTS 二进制音频使用独立有界队列，避免挤占有序控制事件。
- **物理动作权限收紧**：OpenClaw 的动作能力列表固定为空，Gateway 对非标准 Provider 返回的动作再次清除；网页本地控制仍保留独立动作白名单。
- **测试录音治理**：`listen.start` 明确携带 `manual`、`wakeword` 或 `followup` 来源；可只保留手动训练录音，并把 ASR 文本写入受限清单。
- **舵机诊断修正**：保留 R3/L4 的常规 150 度安全上限，仅允许 `forward` 诊断动作使用完整角度范围。

## 发布内容边界

- 仓库包含固件、Voice Gateway、协议 Schema、必要唤醒模型、测试与模型工具源码。
- 个人录音、训练数据、本机 `.env`、虚拟环境、缓存、诊断构建目录、备份与本地发布产物不进入版本库。
- 云端 ASR/TTS、TLS、OpenClaw 凭据和真实硬件接线仍需在每台设备本地配置。

## 验收边界

- 主机测试覆盖采集状态、预录音、连接状态、连续对话、上下行传输、动作隔离、录音治理和既有 Gateway 回归路径。
- 真机语音质量、唤醒阈值、I2S 播放、网络与舵机动作仍以现场设备验收结果为准。
