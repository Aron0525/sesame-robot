Sesame Robot · Reference

OpenClaw 安全配置速查

固定边界：ESP32 → Voice Gateway → OpenClaw sesame Agent。Session 是路由，Gateway cell 才是客户信任边界。

REF—A

目标 Agent 配置骨架

写入前保留现有 Agent；agents.list 是数组，覆盖会替换整个数组。

{
  agents: {
    list: [
      {
        id: "main",
        default: true,
        workspace: "~/.openclaw/workspace"
      },
      {
        id: "sesame",
        workspace: "~/.openclaw/workspace-sesame",
        skills: [],
        memorySearch: {enabled: false},
        sandbox: {
          mode: "all",
          backend: "docker",
          scope: "session",
          workspaceAccess: "none",
          docker: {
            network: "none",
            readOnlyRoot: true,
            capDrop: ["ALL"],
            pidsLimit: 64,
            memory: "512m",
            cpus: 0.5
          }
        },
        tools: {
          profile: "minimal",
          deny: [
            "group:runtime", "group:fs", "group:sessions",
            "group:memory", "group:web", "group:ui",
            "group:automation", "group:messaging", "group:nodes",
            "group:agents", "group:media", "group:plugins",
            "group:openclaw"
          ],
          elevated: {enabled: false},
          exec: {host: "sandbox", security: "deny"}
        }
      }
    ]
  }
}
注意这是基于当前本机配置的目标骨架；agents.list 是替换型数组，所以示例保留了现有 main。正式修改时仍应先用 openclaw agents add 创建 Agent，再合并配置，并执行 openclaw config validate。

固定输出

OpenClaw 只输出 JSON，Voice Gateway 和 ESP32 再校验。

{
  "v": 1,
  "request_id": "req_001",
  "turn_id": "turn_001",
  "status": "completed",
  "reply": {"text": "你好，很高兴见到你。"},
  "voice": {
    "voice_id": "sesame_default",
    "style": "happy",
    "speed": 1.0
  },
  "expression": {"name": "happy", "ttl_ms": 2500},
  "actions": [
    {"name": "wave", "duration_ms": 1200}
  ]
}
REF—C

验证命令

配置文件存在不等于运行时已经生效。

openclaw config validate
openclaw sandbox recreate --agent sesame
openclaw sandbox list --json
openclaw sandbox explain --agent sesame --json
openclaw security audit --deep
openclaw gateway probe
  • 必须显示 session 已 sandboxed。
  • 不得出现 host shell、文件写入、浏览器、消息、node 工具。
  • 不得挂载 Docker socket、用户主目录或凭据目录。
  • 不同客户使用独立 Gateway cell 和凭据。
