# Sesame V3 v1.6.0 发布说明

发布日期：2026-08-17

## 本版本已实现

- **双重语音门控**：语音唤醒词统一为“你好，芝麻”（`ni hao zhi ma`）。MultiNet 命中后还必须通过本机固定口令的主人声纹模板，才会播放“我在”并进入原有的录音流程。
- **本地私有注册**：新增 `tools/train_owner_voiceprint.py`，从至少 10 条、16 kHz 单声道 WAV 注册录音生成设备模板与校准报告。模板、原始录音和报告均不提交到仓库。
- **安全默认值**：模板不存在、音频不足、模板无效或相似度低时都静默拒绝，不会触发语音唤醒。BOOT 按键保留为独立的手动录音入口，不经过声纹判断。
- **可测试实现**：新增纯 C++ 主人声纹门控单元测试和控制器接线检查；门控保存最近 1.5 秒 PCM，并以有声帧的声学特征与本地模板作余弦相似度比较。

## 发布边界

- 该门控用于降低他人说出口令造成的误唤醒，不是安全级声纹认证，不能防录音回放或合成语音。
- 此 tag 不包含 Wi-Fi 密码、device token、TLS 私钥、NVS 配置、真实录音、训练样本或生物模板。

## 验证

- 已执行 ESP32-S3 主机回归脚本，覆盖主人声纹门控的匹配、拒绝、静音与 BOOT 绕过路径。
- 真机唤醒率、阈值和声学表现仍需在目标设备完成烧录后实测。
