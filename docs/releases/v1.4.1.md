# Sesame V3 v1.4.1 发布说明

发布日期：2026-08-06

## 本版本已实现

- **语音唤醒**：ESP32-S3 固件接入本地 WakeNet/VAD 唤醒与回合检测。检测到唤醒后，设备播放本地提示音并开始采集语音；实体按键仍可启动语音回合。
- **站立动作修复**：`stand` 动作已更新舵机映射和动作执行路径，并被加入固件主机测试。
- **既有链路保留**：固件、Voice Gateway、ASR → OpenClaw → TTS、可选联网搜索、OLED 表情和本地网页控制均继续保留。

## 后续需要完成

1. 建立并完善 OpenClaw 的记忆层。
2. 继续修复并实机验收动作的稳定触发、完成确认与异常恢复。
3. 将通用本地唤醒模型替换为“芝麻”专用唤醒词。
4. 自主设计新的动作和表情，并接入设备动作/表情资源。

## 验收边界

本版本的主机测试覆盖站立动作和本地唤醒回合策略。设备在真实硬件上的网络、语音云服务与整机动作闭环，仍需按现场配置继续验收。
