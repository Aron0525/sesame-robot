网关核心术语

用于复习概念边界，不替代完整教材。

术语一句话定义关注层次
Gateway位于通信边界、代理流量并执行统一策略的架构角色泛称
Forward Proxy代表客户端访问外部服务客户端侧
Reverse Proxy代表后端服务接收客户端请求服务端侧
Load Balancer在多个后端实例之间选择目标L4/L7
API Gateway统一暴露并治理应用 API 的七层网关L7
Ingress外部流量进入集群或系统的方向与入口南北向
Egress内部流量访问外部系统的方向与出口南北向
Service Mesh治理服务之间通信的基础设施层东西向
Control Plane管理和下发路由、证书与策略配置控制面
Data Plane实际处理每一个连接与请求数据面
Authentication确认调用者是谁身份
Authorization确认调用者能做什么权限
Rate Limiting限制一定时间内的请求数量或速率流量治理
Circuit Breaker上游持续失败时暂时停止调用，避免级联故障韧性
AI Gateway治理应用到模型供应商之间调用的专门网关LLM 调用
